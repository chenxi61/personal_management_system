# 个人成长档案系统

这是一款使用 Streamlit 和 SQLite 开发的个人信息管理系统，可以记录荣誉、证书、经历和工作记录，并提供完整的数据库增删改查、筛选、统计图表、成长洞察与数据导出功能。

## 安装与启动

Windows 用户完整解压 ZIP 后双击 `启动系统.bat`。脚本从新到旧检测64位稳定版 Python 3.15、3.14、3.13、3.12、3.11、3.10，优先使用较新的已安装版本。每个版本使用独立 `.runtime` 环境，避免沿用旧 `.venv`。

没有可用环境时，通过Windows的winget尝试安装范围内较新的Python最新补丁版；如依赖安装失败，会尝试其他版本。可能出现系统安装提示。电脑没有winget时，需手动安装64位Python稳定版，并勾选 Add Python to PATH。

已解除pandas旧版本上限。首次安装选择当前Python支持的最新稳定依赖，只采用预编译包，避免要求Visual Studio。旧Python可能使用较旧pandas，这是依赖兼容性决定的。之后复用已安装依赖；要更新，可用对应 `.runtime` 环境的python执行 `-m pip install --upgrade --only-binary=:all: -r requirements.txt`。

3.10至3.15是安装器尝试范围，全部版本组合尚未逐一实测；32位、预发布版本及缺少兼容预编译依赖的环境不自动采用。首次运行需要联网，使用期间保持窗口打开。不要双击app.py，也不要在压缩包内启动。

如果浏览器没有自动打开，访问 http://localhost:8501 。关闭启动窗口会停止本地服务，已保存的数据仍然保留。

也可以进入本项目目录后手动运行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器通常会自动打开。如未自动打开，请访问终端中显示的本地网址，一般为 `http://localhost:8501`。

## GitHub 分享说明

本发布包不包含个人数据库、PDF 证书、密码或虚拟环境。其他人下载后在自己的电脑上运行，会创建自己的空数据库，其操作不会影响原作者电脑或阿里云服务器的数据。

GitHub 仓库仅存放代码，上传 ZIP 不会自动运行 Streamlit。建议将 ZIP 解压后，把内部文件（包含 `.streamlit` 和 `.gitignore`）上传到仓库根目录，方便他人直接下载运行。

如果分享阿里云在线网址，访问者仍使用服务器上的同一个数据库。当前版本没有登录和用户数据隔离，在线访问者的修改会影响该服务器的数据。

## 数据库文件

- 系统首次启动时自动创建 SQLite 数据库 `data/growth_archive.db`。
- 数据库包含 `profiles`、`categories`、`records` 和 `certificates` 四个关联表。
- 如果 `data/records.csv` 中存在旧版数据，首次启动会自动迁移到 SQLite。
- 数据库损坏时，系统会先备份原文件，再重建空数据库。
- 页面刷新或重新启动后，已有记录仍然保留。
- 筛选只影响页面展示，不会删除或覆盖其他记录。
- 数据库结构见 `schema.sql`，关系设计见 `ER图.md`。

## 功能

- 新增个人成长记录
- 使用 SQL 查询读取记录
- 修改已保存的记录
- 删除记录及其关联证书
- 关键词、类型和日期范围筛选
- 最新或最早排序
- 统计卡片、环形饼图和月度柱状图
- 可滑动的日期范围及 AI 洞察详细程度组件
- 表格视图和卡片视图
- 上传并持久化保存 PDF 证书
- 在筛选后的表格或成长卡片中下载对应 PDF 证书
- 将全部 PDF 证书打包导出为 ZIP 文件
- 编辑已保存记录，并支持替换或移除 PDF 证书
- 本地规则生成成长建议
- 下载全部数据或当前筛选结果

## 运行自动检查

```powershell
python -m unittest -v test_app.py
```

自动检查覆盖数据库建表、多表外键、SQL 新增、重启后持久化、更新、删除、证书级联删除和输入校验。
