# 个人成长档案系统

这是一款使用 Streamlit 和 SQLite 开发的个人信息管理系统，可以记录荣誉、证书、经历和工作记录，并提供完整的数据库增删改查、筛选、统计图表、成长洞察与数据导出功能。

## 安装与启动

进入本项目目录后运行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器通常会自动打开。如未自动打开，请访问终端中显示的本地网址，一般为 `http://localhost:8501`。

## GitHub 分享说明

本发布包不包含个人数据库、PDF 证书、密码或虚拟环境。其他人下载后在自己的电脑上运行，会创建自己的空数据库，其操作不会影响原作者电脑或阿里云服务器的数据。

GitHub 仓库仅存放代码，上传 ZIP 不会自动运行 Streamlit。建议将 ZIP 解压后，把内部文件（包含 `.streamlit` 和 `.gitignore`）上传到仓库根目录，方便他人直接下载运行。

如果分享阿里云在线网址，访问者仍使用服务器上的同一个数据库。当前版本没有登录和用户数据隔离，在线访问者的修改会影响该服务器的数据。

## 数据库文件

- 系统首次启动时自动创建 SQLite 数据库 `data/growth_archive.db`。
- 数据库包含 `profiles`、`categories`、`records` 和 `certificates` 四个关联表。
- 如果 `data/records.csv` 中存在旧版数据，首次启动会自动迁移到 SQLite。
- 数据库损坏时，系统会先备份原文件，再重建空数据库。
- 页面刷新或重新启动后，已有记录仍然保留。
- 筛选只影响页面展示，不会删除或覆盖其他记录。
- 数据库结构见 `schema.sql`，关系设计见 `ER图.md`。

## 功能

- 新增个人成长记录
- 使用 SQL 查询读取记录
- 修改已保存的记录
- 删除记录及其关联证书
- 关键词、类型和日期范围筛选
- 最新或最早排序
- 统计卡片、环形饼图和月度柱状图
- 可滑动的日期范围及 AI 洞察详细程度组件
- 表格视图和卡片视图
- 上传并持久化保存 PDF 证书
- 在筛选后的表格或成长卡片中下载对应 PDF 证书
- 将全部 PDF 证书打包导出为 ZIP 文件
- 编辑已保存记录，并支持替换或移除 PDF 证书
- 本地规则生成成长建议
- 下载全部数据或当前筛选结果

## 运行自动检查

```powershell
python -m unittest -v test_app.py
```

自动检查覆盖数据库建表、多表外键、SQL 新增、重启后持久化、更新、删除、证书级联删除和输入校验。
